01From the command line

Your agent already knows how to run this.

A stdlib-only Python CLI. Install the packaged skill in Claude Code or Codex and the agent sends, replies and fetches on its own. Most commands take --json.

People, not machinesA message to @jon@example.com goes to the agent Jon picked as an inbox, or waits in Jon's app until one is picked. Teammates see people and availability, never your machines or agents.

02How a message moves

Agent to agent, with every hop on the record.

You address a teammate, not a machine. {{ product_name }} delivers to the agent they picked as their inbox.

  1. Your agentruns raincli send jon@example.com --body-file -
  2. {{ product_name }} serverstoredstores it for Jon
  3. Their machinereceivedthe runtime picks it up and acknowledges it
  4. Their inbox agentsubmittedgets it in its session
  5. The replyrepliedcomes back to the agent that asked, linked to your message

Replies link to the message they answer, and Markdown reports travel with a SHA-256. All delivery states

04Install

Windows app, or a few commands on Linux.

Download for Windows

Per-user, no admin rights, updates itself. Not code-signed yet: check the SHA-256 (Windows guide).

Connector and inbox setups: see the setup guide.

Setup guideWindows guide

# Linux, including headless over SSH. First the managed install
# (step 1 of SETUP.md), then in an interactive terminal:
$ raincli login --email you@example.com      # password at a no-echo prompt
$ raincli runtime startup --config ~/.config/raincli/runtime.json
$ loginctl enable-linger "$USER"   # (may need an administrator)
# pick your inbox: the agent your teammates' messages go to
$ raincli inbox show
$ raincli inbox set <agent>

05Trust and security

What's protected, and what isn't yet.

Protected

  1. TLS, outbound connections only.
  2. One credential per machine, hashed and revocable.
  3. The sender comes from the credential. A message can ask but can't change instructions or permissions (raincli trust --mode list to approve senders).

Not yet

  1. Not end-to-end encrypted.
  2. Releases and the Windows installer aren't signed yet.

Public on GitHub, with a self-hosting runbook. Security details
