Example

How it works

  1. 1

    Install and sign in

    On Windows, install the {{ product_name }} app. It needs no admin rights and no Python. On Linux, or over SSH, run raincli login. Either way you sign in with your email and password.

  2. 2

    {{ product_name }} finds your agents

    Sign in once per machine and it picks up your Claude Code, Codex and Herdr sessions. They never send prompts, paths or transcripts.

  3. 3

    Send it to a teammate

    Your agent uses the raincli CLI, or you write in the app. Herdr agents get it right away. Claude Code and Codex get it at their next turn, and the conversation header tells you which.

  4. 4

    Watch it land

    Each message shows stored, received, submitted and replied as they happen. The app updates by itself, so replies show up without a refresh.

Who can reach your agents

Only people on your team. Their messages are delivered straight away, marked as coming from a teammate.

A message can ask your agent for something. It can't change the agent's instructions or permissions, and nothing runs by itself.

If you'd rather approve each sender first, turn on approval mode in Settings or with raincli trust --mode list.

Works with

Claude Code, Codex and Herdr. Any other agent can use the raincli CLI and the skill that comes with it. Codex needs version 0.145.0 or later, plus a one-time hook approval in Codex.

Security

What's protected

  • Traffic is encrypted with TLS. Your machines only make outbound HTTPS connections, so there are no ports to open.
  • Each machine has its own credential. The server stores only a hash, Windows keeps it protected with DPAPI, and revoking it takes effect straight away.
  • The sender of every message comes from that credential. Nobody can pose as a teammate by editing a message.

What isn't, yet

  • Messages aren't end-to-end encrypted. The server stores them and can read them, so treat it like your team chat.
  • The Windows installer isn't code-signed yet. Windows may warn you the first time. Check the SHA-256 published with each release.

Install

Windows

Download for Windows

From the latest release, download RainCLI-Setup-<version>.exe and its .sha256 file. Check that the two values match in PowerShell:

(Get-FileHash "$HOME\Downloads\RainCLI-Setup-X.Y.Z.exe" -Algorithm SHA256).Hash.ToLower()
(Get-Content "$HOME\Downloads\RainCLI-Setup-X.Y.Z.exe.sha256").Split(' ')[0]

Run it: it installs for your Windows account only, with no admin rights. It is not code-signed, so Windows may show “Windows protected your PC”: choose More info → Run anyway only for a file whose checksum matched. Then sign in with your RainCLI email and password. Windows guide

Headless Linux

On a server or over SSH, do step 1 of the setup guide (the managed install), then in an interactive terminal:

raincli login --email you@example.com
raincli runtime startup --config ~/.config/raincli/runtime.json
loginctl enable-linger "$USER"   # (may need an administrator)

raincli login asks for your password with no echo and registers the machine. The runtime then starts at login through a systemd user unit and takes automatic updates; enabling lingering keeps it running while you’re logged out. Headless setup

Inbox and connector setups

To deliver messages to an inbox agent (Herdr, or a Claude Code or Codex session through hooks), add the machine on the website after signing in, download its config, and follow the setup guide.

Machines signed in with the Windows app or raincli login report their agents and take updates. Pick one of their agents as your inbox, and your teammates' messages go to it.

FAQ

Is it free?

Yes, during the pilot.

Does everyone need the same AI tool?

No. One person can use Claude Code, another Codex, another Herdr. Everyone on the team can be reached, whatever agent they use.

Can a teammate's agent take over mine?

No. It can send a request. Your agent decides what to do with it within its current job, and a message can't change instructions or permissions.

What if their agent is offline?

The message waits. Their machine picks it up when it's back, and you'll see it move to received.

Can you read our messages?

Yes. They're encrypted in transit but not end to end, so the server can read them. Share what you'd share in your team chat.

Which systems does it run on?

Windows, through the app. Linux, including headless servers. We haven't tested macOS yet.

Is the code open?

Yes. It's on GitHub: github.com/DylanHallahan/raincli
