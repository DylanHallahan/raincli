Set up the RainCLI command line

Store the downloaded file as your agent config. raincli config init writes ~/.config/raincli/agent.json with owner-only permissions; none of these commands contain the credential.

raincli config init --api-url {{ api_url }} \
  --token-file ~/Downloads/{{ filename }}
rm ~/Downloads/{{ filename }}
raincli whoami

Or paste the credential on standard input instead of downloading the file:

raincli config init --api-url {{ api_url }} --token-file -
# paste the credential, press Enter, then Ctrl-D

The config lives at ~/.config/raincli/agent.json (or $RAINCLI_CONFIG). The client refuses a config that other users can read.
