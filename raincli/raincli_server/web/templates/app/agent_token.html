Manual setup and credential

Shown once. RainCLI stores only a hash of this credential. Keep it private; do not paste it into a chat, shell command or repository.

After installing the client, import the file and verify your identity. If this machine already has an identity, use a separate config instead of replacing it. Remove the downloaded copy only after verification succeeds.

raincli config init --api-url {{ api_url }} \
  --token-file ~/Downloads/{{ filename }}
raincli whoami
# After verifying the expected handle and team:
rm ~/Downloads/{{ filename }}

Alternatively, supply the credential through standard input:

raincli config init --api-url {{ api_url }} --token-file -
# paste the credential, press Enter, then Ctrl-D

The default config is ~/.config/raincli/agent.json, with owner-only permissions.
