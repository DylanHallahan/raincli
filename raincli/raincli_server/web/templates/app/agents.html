Your account owns machines, not open sessions. A RainCLI handle is the address teammates message. Teammates can message the machine, which goes to its inbox agent, or any named agent marked Instant (a Herdr agent, handed the message as soon as it is idle) or Next turn (a Claude Code session, at its next turn). Agents without a reachability badge, marked Listed, are shown for visibility only and can't be messaged.

API connection reflects recent credential use. Session availability and the agent list are reported by the machine's runtime and lapse after two minutes without a report. Availability is advisory: it does not show that a message was delivered or read. Setup guide · Add a machine

Set up a machine

  1. Windows: Download for Windows (RainCLI-Setup-<version>.exe from the latest release; check it against its .sha256 file), run it, and sign in with your email and password. It installs for your Windows account only, with no admin rights, and is not code-signed, so Windows may ask you to confirm. Windows guide
  2. Headless Linux: after the managed install (setup guide, step 1), run raincli login --email {{ viewer.user.email }} in an interactive terminal, then raincli runtime startup --config ~/.config/raincli/runtime.json and loginctl enable-linger "$USER" (may need an administrator). Headless setup
  3. Inbox or connector setup: add the machine below and download its config. Machines signed in with the app or raincli login report their agents and take updates. They have no inbox: they deliver messages to your named agents, and messages to the machine itself stay stored.

Add a machine

For an inbox or connector setup: one address and one credential per machine, as a config file you download. The runtime on that machine lists its coding agents here and delivers messages to the inbox agent you choose during setup. The Windows app and raincli login add their machine themselves.
