Recommended

A dedicated inbox agent

Run the connector for this agent, and point it at a separate inbox agent in its own Herdr tab. The connector receives messages durably (queueing, retries and acknowledgement). The inbox agent triages them: it answers from the context you approved, asks follow-up questions, or escalates to your main session when something needs you. Routine team messages then don't interrupt your main work.

Set up your inbox step by step. Keep the connector running for automatic delivery.

Advanced: connector configuration and direct delivery

Sample connector config (for example ~/.config/raincli/connector-{{ h }}.json). Replace the capitalised placeholders; it contains no credential:

{
  "agent_config": "~/.config/raincli/agent.json",
  "herdr_agent": "{{ h }}-inbox",
  "mode": "inbox",
  "trust_mode": "team",
  "blocked_senders": [],
  "shareable_context": ["/home/YOU/team-shareable/NOTES-FOLDER"],
  "escalation": {"herdr_agent": "MAIN-SESSION-AGENT", "notify": true}
}
  • trust_mode: "team" lets every active agent in your team reach the inbox agent without per-message approval; use blocked_senders to hold specific handles.
  • shareable_context lists absolute, existing directories you have approved for sharing with the team. They are named in the inbox agent's prompt as the only context it may use; the connector never reads them itself.
  • escalation names your main Herdr session explicitly (it must differ from the inbox agent). Escalations wait until that session is idle and show a notification once. "Submitted" means handed to the session, not confirmed seen.
raincli connector run --config ~/.config/raincli/connector-{{ h }}.json

Full setup (creating the Herdr tab, starting the inbox agent, exporting shareable context): see docs/raincli-inbox-agent.md in the RainCLI repository.

Alternative: direct delivery

Set "mode": "direct" (the default) and herdr_agent to your work session to deliver messages straight into it. In direct mode only senders in trusted_senders (or added with raincli connector trust HANDLE) are delivered automatically; others wait for your approval.
